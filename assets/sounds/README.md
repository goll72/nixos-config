Neue
====

This sound theme is mostly a replica of [Communitheme Sounds](https://github.com/madsrh/communitheme-sounds),
with the following changes:

 - `message-new-instant` is also used for `message` and `message-new-email`
 - `dialog-error` and `dialog-question` have been boosted
 - added a chime effect for `alarm-clock-elapsed`
 - added a click effect for `camera-shutter`/`screen-capture`
